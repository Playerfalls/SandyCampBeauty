# 💄 SandyCampBeauty — Site para Lash Designer

Site desenvolvido para apresentar os serviços de uma profissional da área de beleza, funcionando como vitrine digital e canal de contato para clientes.

O projeto foi desenvolvido por mim com auxílio do **Claude Code**, utilizando IA como ferramenta de apoio durante o processo de desenvolvimento, ajustes e evolução do site.

## 🌐 Acesso

**Site:** https://sandycampbeauty.com.br

## 📋 Sobre o projeto

O SandyCampBeauty foi criado para oferecer uma presença digital profissional para o negócio, permitindo que clientes conheçam os serviços oferecidos e tenham acesso às informações de atendimento.

O site apresenta serviços como:

* Fio a fio clássica
* Volume luxo
* Volume brasileiro
* Mega volume
* Fox Eyes
* Sobrancelhas
* Sobrancelhas com henna
* Brow Lamination
* Micropigmentação

## 🎯 Objetivos

* Criar uma vitrine digital para os serviços
* Apresentar os procedimentos de forma organizada
* Facilitar o contato com clientes
* Criar uma identidade visual para o negócio
* Disponibilizar o site publicamente através de domínio próprio

## 🛠️ Desenvolvimento

O projeto foi desenvolvido com auxílio de ferramentas de inteligência artificial, utilizando o **Claude Code** como ferramenta de apoio para implementação, ajustes e desenvolvimento de funcionalidades.

A publicação e configuração do projeto foram realizadas em conjunto, incluindo a configuração do domínio e hospedagem.

## 🚀 Publicação

O projeto foi publicado utilizando o **Netlify**, com domínio personalizado:

**sandycampbeauty.com.br**

Também foram realizadas configurações de DNS e SSL para disponibilizar o site de forma segura através de HTTPS.
